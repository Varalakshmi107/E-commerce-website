# E-commerce-website

## About the Project
This is a Full Stack E-Commerce Website developed as a learning project by following the GreatStack YouTube tutorial.
The project helped me gain practical knowledge of modern web development, React components, API integration, database connectivity, and e-commerce functionality.

## Features
- User-friendly interface
- Product listing and product details
- Product collection and categories
- Shopping cart functionality
- User authentication
- Order management
- Responsive design
- Payment integration

## Technologies Used
- HTML5
- CSS3
- JavaScript
- React.js
- Tailwind CSS
